The pipeline **did not generate new features** (`engineered_features` list is empty). However, the following transformations were applied implicitly:

1. **Missing‑value imputation** (median for numeric, mode for categorical).  
2. **Numeric conversion of `Ticket`** (originally a string) to enable correlation analysis.  
3. **Retention of high‑cardinality identifiers** (`PassengerId`, `Name`) – recommended for exclusion in modeling (see Section 7).

## 7. Predictive Modeling Blueprint  

### 7.1 Target & Problem Definition  

- **Target:** `Survived` (binary classification).  
- **Rows:** 891 (small dataset – careful validation required).  
- **Features:** 12 columns (after dropping identifiers).  

### 7.2 Recommended Modeling Stack  

| Algorithm | Why It Fits |
|-----------|-------------|
| **Regularized Logistic Regression** (L1/L2) | Baseline, interpretable coefficients, handles multicollinearity. |
| **Random Forest Classifier** | Captures non‑linear interactions, robust to outliers, provides feature importance. |
| **Gradient Boosting (XGBoost / LightGBM)** | State‑of‑the‑art performance on tabular data, handles missing values internally. |
| **Support Vector Machine (SVM)** | Effective with high‑dimensional sparse data; useful for comparison. |

### 7.3 Feature Selection & Pre‑processing  

1. **Exclude** `PassengerId` and `Name` (high cardinality, no predictive power).  
2. **Encode** categorical variables:  
   - `Sex` → binary (0/1).  
   - `Embarked` → one‑hot (3 columns).  
   - `Cabin` → one‑hot of the most frequent cabins or extract deck.  
3. **Scale** numeric features (`Age`, `Fare`, `Ticket`) using StandardScaler (only for linear models).  
4. **Rank** features via:  
   - **Permutation importance** (cross‑validated).  
   - **Mutual information** for categorical‑numeric interactions.  
5. **Remove** any pair of features with absolute correlation > 0.85 (none observed).  

### 7.4 Validation Strategy  

- **Stratified K‑Fold Cross‑Validation** (k = 5) to preserve the survival rate in each fold.  
- **Metrics**:  
  - **Balanced Accuracy** (handles class imbalance).  
  - **Macro‑averaged F1** (overall classification quality).  
  - **Precision‑Recall AUC** (focus on minority class).  
  - **Confusion Matrix** (interpretability).  

### 7.5 Over‑fitting Mitigation  

| Technique | Implementation |
|-----------|----------------|
| **Regularization** (L1/L2) | Tune `C` (inverse regularisation strength) for logistic regression. |
| **Tree Constraints** | Limit `max_depth`, set `min_samples_leaf`, and use `subsample` for Random Forest / Gradient Boosting. |
| **Hyper‑parameter Search** | Perform Grid/Random search *inside* each CV fold (nested CV) to avoid leakage. |
| **Early Stopping** (for boosting) | Stop training when validation loss stops improving. |

### 7.6 Expected Baseline Performance  

Based on literature and the identified significant predictors, a **logistic regression** model typically achieves **≈ 0.78 – 0.80** balanced accuracy on this dataset. Ensemble methods (Random Forest, Gradient Boosting) can push performance to **≈ 0.82 – 0.85** when engineered features (e.g., `FamilySize`, `Title`) are added.

## 8. Key Take‑aways  

| Insight | Business Relevance |
|---------|--------------------|
| **Sex** is the strongest single predictor of survival (p ≈ 0). | Highlights gender‑based survival disparity – a classic historical observation. |
| **Passenger class** (`Pclass`) and **Fare** are strongly linked to survival (negative and positive correlations, respectively). | Socio‑economic status heavily influenced rescue priority. |
| **Cabin** and **Embarked** retain significant predictive power despite high missingness, thanks to mode imputation. | Even sparse location data can be valuable. |
| **Age** shows a weak, non‑significant linear relationship with survival, but outlier analysis reveals a small group of very young passengers with higher survival. | Suggests non‑linear age effects (e.g., “children” vs. “adults”). |
| **Ticket number** (numeric surrogate) is statistically significant, likely reflecting hidden patterns (e.g., group bookings). | May be a proxy for family or travel class. |
